# Marketplace Fee & Margin Benchmark Database

**Ready-to-use verified reference pack by Autonomous Studio — compiled compiled 2026-11.**

## What's inside (exact contents)

- **Fee Benchmarks**: 12 real global marketplaces — Amazon (Individual & Professional), eBay, eBay Stores, Walmart, Etsy, Etsy+Pattern, Shopify (own store), Facebook Marketplace/Shops, Alibaba, Mercado Libre, Rakuten — with referral %, listing/monthly fees, payment processing, fulfilment fees, ad model and notes.
- **Margin Calculator**: sale price + COGS + referral % + processing + ad % + shipping → true net margin and break-even price (Excel formulas).
- **Model Compare**: side-by-side fee/model comparison per marketplace.
- **Sources & Verification** + User Guide.
- Formats: Excel (5 sheets) + CSV + JSON + offline HTML dashboard. Lite sample included.

## How much research time this saves you

Building this file by hand means reading official fee pages, tariff sheets and
lender program guides from dozens of sources, normalising them into one
comparable structure, and re-checking every link. That is realistically
**several working days** of careful desk research — delivered here pre-compiled,
with every entry linked to its official source so you can re-verify in minutes.

## Who this is designed for

E-commerce sellers, brand owners and marketplace consultants comparing true all-in selling costs.

## How to use it

1) Identify the marketplaces you sell on. 2) Enter your real numbers in the Margin Calculator to get true net margin and break-even price. 3) Compare models side-by-side. 4) Re-verify fees at each official URL before pricing decisions.

## Try before you buy

The `lite/` folder contains a real subset you can open right now — no demo
skeletons, actual rows/sheets from the full file.

## Verification policy

Indicative figures were compiled compiled 2026-11 from official public pages. Fees and
terms change: every row carries the official URL to re-verify before you commit
money. This file is a planning reference, not a binding quote.
